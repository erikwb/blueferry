# BlueFerry-Dokumentation

BlueFerry bringt SMS, RCS und iMessage von einem gekoppelten iPhone über
Bluetooth auf den Linux-Desktop. Es braucht keinen Mac als Relais, keine
Apple-Anmeldung, keine iPhone-App, keinen Cloud-Dienst und kein Abo.

> **Hinweis:** BlueFerry ist noch experimentell. Apple kann das
> Bluetooth-Verhalten ändern, auf das BlueFerry angewiesen ist. Verlasse dich
> für wichtige Nachrichten deshalb noch nicht allein darauf.
