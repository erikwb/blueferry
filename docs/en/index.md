# BlueFerry documentation

BlueFerry brings SMS, RCS, and iMessage from a paired iPhone to your Linux
desktop over Bluetooth. There is no Mac relay, Apple login, iPhone app, cloud
service, or subscription.

> **Note:** BlueFerry is still experimental. Apple can change the Bluetooth
> behavior it relies on, so don't make it your only way to receive an
> important message yet.
